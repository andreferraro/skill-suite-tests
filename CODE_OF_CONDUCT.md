# Código de Conduta

## Compromisso

Este projeto recebe contribuições técnicas de pessoas com experiências diferentes. A participação deve ser profissional, respeitosa e focada no trabalho.

## Comportamento esperado

- Criticar ideias, código e evidências sem atacar pessoas.
- Explicar discordâncias com contexto técnico verificável.
- Respeitar privacidade, autoria e limites de acesso.
- Corrigir erros de forma transparente.

## Comportamento inaceitável

- Assédio, discriminação, ameaça ou intimidação.
- Exposição de dados pessoais, credenciais ou comunicação privada.
- Ataques pessoais, provocação persistente ou interrupção deliberada da colaboração.
- Uso do projeto para atividade ilegal ou acesso não autorizado.

## Aplicação

Relate incidentes de forma privada pela [área de segurança do repositório](https://github.com/andreferraro/skill-suite-tests/security/advisories/new) e identifique o relato como uma questão de conduta. O mantenedor pode editar ou remover conteúdo e limitar a participação para proteger o projeto e seus participantes.
